# Manuscript Visual Assets

Each table or figure has its own folder with `data/`, `images/`, and `README.md`.
The `data/` folders contain copied source CSV/JSON/NPZ/PNG files needed to redesign the figure or table.
The `images/` folders contain current manuscript-ready PNG previews or copied source figures.

Current main-manuscript set follows the figure/table order in the manuscript:
- `figure_01_workflow`
- `table_01_id57_template_scoring`
- `figure_02_id57_matching_examples`
- `figure_03_id57_radial_control`
- `figure_04_groel_density_projection`
- `table_02_numerical_validation_summary`

Regenerate the underlying validation outputs using the reproducibility guide. If the asset organizer is rerun, update it to preserve the canonical manuscript-order folder names listed above.
