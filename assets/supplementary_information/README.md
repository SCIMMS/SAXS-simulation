# Supplementary Asset Package

The current [Revision assets](revision/README.md) contain 22 figures and 21 tables, with current numbering, editable table CSVs and publication-resolution figures. Earlier directories retain the numerical evidence and historical asset order.

Each supplementary figure or table has its own folder. When present, the `images` directory contains the figure or table image intended for the Supporting Information document, and the `data` directory contains the source data or summary files needed to recreate or audit the figure/table.

Historical contents:
- `figure_S01_groel_structure_preview`: C-alpha structural preview generated from public PDB 1SS8 and the BIOMT copy transform used for the D7 tetradecamer model.
- `figure_S02_groel_density_projection`: GroEL density slices, mesh/stencil projection validation, and mesh-decimation behavior.
- `figure_S03_id57_expanded_examples`: expanded four-example ID57 matching panel and retrieval/control data.
- `figure_S04_groel_model_variants`: GroEL model-variant preview panels and pattern/profile data.
- `figure_S05_groel_radial_control`: GroEL protein-derived template versus radial-profile randomized control score comparison.
- `figure_S06_mass_conservation_convergence`: projected-mass conservation and resolution-convergence plots.
- `figure_S07_runtime_scaling`: image-size and q-grid runtime scaling plots.
- `figure_S08_memory_cost_comparison`: dense voxel, projected-image, and mesh-array memory comparison.
- `table_S01_groel_parameters`: GroEL density, mesh, template-library, and control-comparison summary data.
- `table_S02_id57_parameters`: fixed ID57 template-library, self-retrieval, and structured-versus-control summary data.
- `table_S03_id57_public_data_metrics`: compact ID57 public-data and template-scoring metric summary.
- `table_S04_benchmark_environment`: benchmark environment, measurement scope, and source summary files.
- `table_S05_numerical_validation_summary`: detailed numerical validation summary table.
- `table_S06_orientation_throughput`: 1,000-orientation library throughput summary.
