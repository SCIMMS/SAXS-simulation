Supplementary asset package for the manuscript.

Each supplementary figure or table has its own folder. The `images` directory contains the figure image intended for the Supplementary Information document, and the `data` directory contains the source data or summary files needed to recreate or audit the figure/table.

Current contents:
- `figure_S01_groel_structure_preview`: C-alpha structural preview generated from public PDB 1SS8 and the BIOMT copy transform used for the D7 tetradecamer model.
- `figure_S02_id57_full_retrieval_examples`: expanded four-example ID57 retrieval panel and retrieval/control data.
- `figure_S03_groel_model_variants`: GroEL model-variant preview panels and pattern/profile data.
- `figure_S04_groel_real_vs_control`: GroEL protein-derived template versus radial-profile randomized control score comparison.
- `table_S01_groel_parameters`: GroEL density, mesh, template-library, and control-comparison summary data.
- `table_S02_id57_parameters`: fixed ID57 template-library, self-retrieval, and structured-versus-control summary data.
- `table_S03_benchmark_environment`: benchmark environment, timing scope, and source summary files moved from the main table set.
