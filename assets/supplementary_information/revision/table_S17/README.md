# Table S17

Table S17 Preserved actual-data conditional fitting examples with equal frame weights. ID57 and GroEL have different count units, ROI and geometry; loss magnitudes and percentages are not cross-dataset performance rankings. Bulk means global geometry and scale and background adjustment with angular modes fixed at zero: ID57 varies scale, two aspects, rounding, three rotations, signal and background; GroEL varies three axis scales, three rotations, two detector offsets, signal and background. Reduction is one minus the ratio of equal-frame mean test log-MSE to that of the starting mesh template, expressed as a percentage. Improved/worsened counts compare per-frame test log-MSE with that same start. Additional modes provide only modest gains over bulk adjustment. These are supplementary application examples, not the article's primary results.

`data/table.csv` is an editable transcription of the current native article table, preserving displayed values, precision and units. Unrounded numerical evidence and reproduction instructions are indexed in the [current validation package](../../../../validation_package/revision/README.md).
