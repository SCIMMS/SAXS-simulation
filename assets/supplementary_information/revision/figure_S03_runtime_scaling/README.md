# Figure S3

Figure S3 Runtime scaling for projected-density pattern generation. (a) Median single-pattern runtime as the projected-density image size is increased at fixed 257 × 257 q-grid size. (b) Median projection and CZT times as the q-grid size is varied at fixed 512 × 512 projected-image size. The comparison shows that projected-density image size affects both projection and transform work, whereas q-grid size primarily increases the CZT cost.
