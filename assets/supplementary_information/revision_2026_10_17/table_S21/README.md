# Table S21

Table S21 GPU-resident complex128 two-dimensional tail timings on an RTX 2070 SUPER with 8 GB memory, under Windows 10 with Python 3.13.13, NumPy 2.4.6 and CuPy 13.6.0. Medians use 30 alternating-order repetitions after 25 interleaved warmup cycles. The same detector-plane CZT target is used in both routes.

`data/table.csv` transcribes the final R18 native Word table, preserving displayed rounding, units and footnote symbols. Unrounded measurements and conditions are in the [validation package](../../../../validation_package/revision_2026_10_17/README.md). Tables remain editable CSV; there is no redundant raster table preview.
