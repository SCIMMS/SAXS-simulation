# Figure S11: groel density projection

GroEL density construction, projection validation, and mesh-decimation behavior. (a) Orthogonal mid-slices through the smoothed PDB-derived electron-density grid. (b) Comparison of the reference density projection with layer-weighted mesh projections from the original and decimated meshes, including residual maps. (c) Decimation summary showing point and cell reduction, relative volume error, and projection-level error metrics across density thresholds. This supplementary figure documents whether the protein-density-derived mesh representation preserves the low-q projected-density quantities used by the forward model.
