# Figure S12: groel model variants

GroEL synthetic model previews. The top row shows smooth simulated diffraction intensity for a C7 heptamer A, a D7 tetradecamer B and two B polyprism variants at preview rotation index r0; it does not show projected density. The preview labels P35/P55 refer to the R35/R55 prism variants. The bottom row shows independently normalized Poisson-like synthetic display realizations, not measured or calibrated experimental noise. The preview annulus extends from 5 to 60 pixels, while the scored experimental ROI is 5–40 pixels. A r0 is a heptamer preview at quaternion [0.5, −0.5, −0.5, −0.5], not identity orientation or an experimental fit. The scored library does not contain A; no A-versus-B retrieval preference follows from these panels.
