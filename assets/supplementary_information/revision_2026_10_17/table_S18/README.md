# Table S18

Table S18 Five-plane supplementary fit sensitivity. Effective R is the mean of sphere-fit radii over the eight transformed corner caps for one fitted model; anisotropy means it is not a common local curvature radius. The table reports its median (interquartile range) across frames; test reduction uses equal-frame mean log-MSE relative to the same coarse rounded-grid seeds (0.492640). Aspect/scale bound counts can overlap. These quantiles are not uncertainty intervals or local curvature radii.

`data/table.csv` transcribes the final R18 native Word table, preserving displayed rounding, units and footnote symbols. Unrounded measurements and conditions are in the [validation package](../../../../validation_package/revision_2026_10_17/README.md). Tables remain editable CSV; there is no redundant raster table preview.
