3. Numerical validation using analytical and synthetic references

This section tests whether the projected-density simulation kernel described in Section 2 behaves as expected under controlled conditions. The tests use analytical or synthetic reference objects only; no experimental detector frames, masks, PONI geometry files, or private morphology-specific datasets are used. The validation asks four questions: whether signed rasterization reproduces known projected densities and scattering patterns, whether projected mass is conserved across orientation, whether mesh and detector-plane refinements converge, and whether the chirp z-transform reproduces direct DFT results on a controlled grid.

3.1. Validation metrics and reference quantities

For each reference object, projected density, detector-plane amplitude, and intensity were compared with analytical or high-precision references. The primary error measure was the relative L2 error,

\[ \epsilon_X = \frac{\|X_{\mathrm{sim}} - X_{\mathrm{ref}}\|_2}{\|X_{\mathrm{ref}}\|_2}. \]

This metric was applied to projected density, complex scattering amplitude, and intensity, depending on the available reference. Pattern similarity was summarized using the Pearson correlation between simulated and reference intensity images. Because the projected-density method is a mass-conserving surface accumulation scheme, the projected mass was evaluated as

\[ M_T = \sum_p T_p \Delta u \Delta v. \]

For a closed uniform-density object, this value should agree with the object volume multiplied by density contrast. The zero-frequency scattering amplitude provides an independent consistency check because

\[ A(0,0) = M_T. \]

Together, these checks separate the main numerical error sources: projected mass versus mesh volume tests signed surface accumulation, projected density versus analytical thickness tests rasterization, scattering-pattern agreement tests the combined projection and transform, and CZT-versus-direct-DFT agreement tests detector-plane sampling independently of the shape reference.

3.2. Analytical validation with sphere, ellipsoid, and box references

The first validation set used a sphere, a rotated ellipsoid, and a rectangular box. The sphere and ellipsoid were represented by triangular meshes generated at resolution 96, giving 36,480 faces in each case. The detector-plane projection grid was 512 by 512 pixels, and the low-q scattering grid used qmax = 25.0 with 257 samples along each reciprocal-space axis.

For the unit sphere, the projected-density relative L2 error was 7.97 x 10^-4, the complex-amplitude relative L2 error was 4.89 x 10^-4, and the intensity relative L2 error was 7.52 x 10^-4. The intensity-pattern correlation with the analytical reference was 0.999999981. The projected mass was 4.186899, compared with an analytical volume of 4.188790 and a mesh volume of 4.186921. Thus the projected mass differed from the analytical sphere volume by -4.51 x 10^-4, but from the mesh volume by only -5.28 x 10^-6. This distinction matters because the finite triangular mesh is itself a discretized approximation to the smooth analytical sphere.

The ellipsoid test used semi-axes 1.0, 0.65, and 0.42 with a nontrivial orientation. The projected-density, complex-amplitude, and intensity relative L2 errors were 7.88 x 10^-4, 4.53 x 10^-4, and 7.50 x 10^-4, respectively, with an intensity-pattern correlation of 0.999999982. The projected mass was 1.143028, compared with an analytical volume of 1.143540 and a mesh volume of 1.143030. The projected mass therefore differed from the analytical volume by -4.47 x 10^-4, but from the mesh volume by only -1.36 x 10^-6.

The box test provides a complementary reference because the object is exactly polyhedral and can be represented by only 12 triangular faces. For a box with half-lengths 1.0, 0.72, and 0.45, the simulated intensity agreed with the analytical box intensity with a relative L2 error of 4.07 x 10^-5 and a pattern correlation of 0.999999999. The projected mass was 2.592022, compared with an analytical and mesh volume of 2.592000, giving a relative mass error of 8.38 x 10^-6. A separate small-grid divergence-form check gave a complex-amplitude relative L2 difference of 6.92 x 10^-14, confirming internal consistency of the polyhedral surface contribution.

Together, these tests show that the kernel reproduces analytical low-q references to better than 10^-3 for smooth meshed objects and substantially better for the exact polyhedral box case. The smooth-object error is dominated by finite mesh and raster-grid approximation rather than by a failure of the signed accumulation rule, as shown by the much smaller projected-mass error relative to the actual mesh volume.

3.3. Projected-mass conservation across orientation

The signed-rasterization method should preserve total projected mass for any orientation of a closed, consistently oriented mesh. This was tested by rotating a sphere, an ellipsoid, a box, and an icosahedron, giving 800 orientation cases in total.

When projected mass was compared with the corresponding mesh volume, the maximum absolute relative errors were 1.18 x 10^-5 for the sphere, 4.07 x 10^-5 for the ellipsoid, 7.07 x 10^-5 for the box, and 1.03 x 10^-4 for the icosahedron. Mean errors relative to mesh volume were close to zero for the box and icosahedron and were -1.65 x 10^-6 for the sphere and -7.93 x 10^-6 for the ellipsoid. These values indicate that front-facing and back-facing surface contributions cancel correctly across rotations and that no orientation-dependent mass drift is introduced.

The smooth sphere and ellipsoid show larger systematic errors when compared with ideal analytical volumes, with maximum absolute errors of 6.54 x 10^-4 and 6.83 x 10^-4, respectively. This is expected because the finite mesh volume differs slightly from the exact smooth-body volume. For validating the projection kernel itself, the mesh-volume comparison is the stricter diagnostic because it asks whether the rasterized projection conserves the volume of the object actually being simulated.

3.4. Mesh and detector-plane resolution convergence

Resolution convergence was evaluated in two ways: the detector-plane image size was varied for a fixed high-resolution sphere mesh, and the ellipsoid mesh resolution was varied while the detector-plane image size was held fixed.

For the sphere detector-resolution sweep, image sizes of 128, 256, 512, and 1024 pixels were tested using a mesh with 65,024 faces. Across this range, the projected-density relative L2 error remained between 3.65 x 10^-4 and 4.50 x 10^-4, and the intensity relative L2 error remained between 3.08 x 10^-4 and 4.25 x 10^-4. The intensity-pattern correlation stayed above 0.999999993 for all detector resolutions, indicating that the selected detector-plane sampling is already stable for the low-q reference pattern.

For the ellipsoid mesh-resolution sweep, the mesh resolution was varied from 24 to 128, increasing the number of faces from 2,208 to 65,024. The projected-density relative L2 error decreased from 1.06 x 10^-2 to 4.42 x 10^-4, and the intensity relative L2 error decreased from 1.19 x 10^-2 to 4.21 x 10^-4. The intensity-pattern correlation increased from 0.999995514 to 0.999999994.

This convergence behavior is consistent with the analytical-shape tests. For smooth objects, the dominant error at coarse resolution comes from the finite triangular approximation to a curved surface. Increasing mesh resolution reduces this geometry error, after which the remaining differences are governed by raster-grid and transform-sampling accuracy.

3.5. Chirp z-transform and q-space sampling validation

The projected-density framework uses the chirp z-transform to sample a selected detector-plane q-space window directly. Its numerical correctness was tested by comparing the CZT result with a direct DFT calculation on a small controlled grid.

For the CZT validation case, qmax was 18.0 and the reciprocal-space grid contained 49 samples along each axis. The complex-amplitude relative L2 difference between the CZT and direct DFT was 1.65 x 10^-13, and the corresponding intensity relative L2 difference was 3.16 x 10^-13. These values are at numerical precision for the tested grid and show that the CZT implementation reproduces the intended discrete transform.

The same test checked phase behavior under real-space translation. After accounting for the analytical phase factor, the translated-amplitude relative L2 difference was 2.91 x 10^-16. The translated intensity differed from the original intensity by 4.60 x 10^-16, as expected because translation changes scattering phase but not intensity. The zero-frequency amplitude was also consistent with projected mass, with a relative difference of 1.50 x 10^-13.

These checks validate detector-plane sampling independently from mesh geometry and show that the CZT does not introduce measurable q-space scaling, phase, or zero-frequency normalization errors in the tested configuration.

3.6. Numerical validation summary

The analytical and synthetic tests support the numerical assumptions used by the forward-simulation framework. Signed projected-density rasterization conserves mesh-defined volume across orientation, reproduces analytical projected densities and low-q scattering patterns for smooth reference objects at approximately 10^-3 relative error, and gives substantially smaller errors for an exactly polyhedral reference object. Mesh refinement reduces the dominant smooth-object approximation error, detector-plane sampling remains stable over the tested image sizes, and the CZT implementation agrees with direct DFT to numerical precision while preserving q=0 mass normalization and translation-phase behavior.

The scope of this validation is deliberately limited. It establishes the numerical correctness of the ideal sample-level simulation kernel under controlled analytical and synthetic conditions, but does not validate detector response, photon-counting statistics, experimental background, beamline geometry calibration, or fluence normalization. The next section evaluates computational performance and memory scaling, while Section 5 tests application-level behavior using public CXIDB data and public protein-structure-derived models.
