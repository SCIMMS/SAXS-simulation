5. Public-data application and protein-density modeling

Sections 3 and 4 evaluated numerical accuracy and computational cost under controlled analytical and synthetic conditions. This section tests the same workflow in reproducible public-data settings. The aim is not to claim unique three-dimensional structure determination from individual low-q shots, but to ask whether structured candidate models explain dominant detector-plane features better than controls, and whether the mesh workflow extends to protein-density-derived models.

The first part uses CXIDB ID57 nanoparticle data as the main retrieval-oriented validation case, with synthetic self-retrieval, public experimental retrieval, and a radial-profile-preserving randomized control. The second uses GroEL as a protein-density modeling demonstration. The GroEL case is not treated as a stringent single-shot orientation-retrieval benchmark.

5.1. Public-data validation strategy

Single-shot low-q diffraction images are ambiguous because orientation, detector coverage, beamstop masking, background scattering, photon statistics, and fluence variation all affect the measurement. The validation question is therefore whether a physically motivated candidate library reproduces measured low-q features better than a control library that preserves simpler intensity statistics.

Experimental images and templates were compared inside masked annular ROIs using log1p-transformed intensities. For each frame-template pair, the template was linearly scaled with a constant background term before scoring. The primary score was normalized log-intensity correlation, with residual log-z RMS as a complementary fit-error measure. These scores compare candidate libraries but do not prove that a top-ranked template is the true orientation, because experimental orientation ground truth is unavailable.

The control strategy tested information beyond the radial intensity envelope. In both ID57 and GroEL, radial-profile-preserving randomized templates were generated by permuting pixel values within one-pixel radial bins inside the active annular ROI. The structured and control libraries then used the same masks, ROI, transform, and fitting procedure, so a real-versus-control separation measures angular or model-specific information rather than a preprocessing advantage.

5.2. CXIDB ID57 nanoparticle data and template construction

The first public application used CXIDB ID57 normal-incidence nanoparticle patterns. The public CXI file contained 209 detector images of size 401 by 401 pixels. A fixed core-shell candidate model was used: an outer Pd cube shell with side length 52.0 nm and an inner Au octahedral core with vertex radius 26.2 nm. The relative density contrasts were 1.0 for Pd and 1.5 for Au.

The simulation used the public detector geometry and a 384-pixel projection grid. The orientation library contained 240 symmetry-aware rotations sampled over a small normal-incidence tilt cap with proper octahedral/cubic symmetry reduction. These model and simulation parameters were fixed before experimental retrieval; only the per-template intensity scale and constant background term were fitted. 5.3. Synthetic self-retrieval check for ID57

Before experimental retrieval, the pipeline was tested using noisy synthetic queries generated from the same 240-orientation library and clean templates as the reference library. This checks masking, log-intensity scoring, scale/background fitting, and symmetry-aware indexing under known-orientation conditions.

All 240 noisy synthetic queries retrieved the correct clean-template index, giving exact-index accuracy 1.0. The median log-correlation score was 0.966886, and the symmetry-aware octahedral error was 0 degrees for the median, 95th percentile, and maximum. This check confirms recovery of known library members under realistic noise and masking, but it does not by itself validate the experimental interpretation because the query and library share the same generative model.

5.4. Retrieval against public ID57 experimental frames

The structured ID57 library was then evaluated against all 209 public experimental frames and compared with the radial-profile-preserving randomized control. Because the control library was generated by radial-bin scrambling of the same template stack, each paired comparison used matched detector geometry, template count, ROI, and scoring procedure.

The structured library clearly outperformed the radial control. Across 209 paired comparisons, the structured median log-correlation score was 0.724752, while the radial-control median was 0.443121. The structured library scored higher in all 209 of 209 frames, with a two-sided sign-test p-value of 2.43 x 10^-63. The residual metric gave the same conclusion: the structured template had lower residual in all paired comparisons.

These results support the application-level ID57 validation claim. The structured core-shell library is not merely matching an average radial envelope; it captures model-specific two-dimensional low-q features present in the public images. Because individual-frame ground-truth orientations are unavailable, the result should not be interpreted as proof that every top-ranked template is the true orientation.

5.5. GroEL protein-density construction from a public PDB structure

The second public-data case tested extension to protein-scale density-derived mesh models. The input was public GroEL structure 1SS8. Non-hydrogen atoms were converted into a smooth electron-density approximation using Waasmaier-Kirfel-inspired Gaussian scattering-factor terms. A structural preview of the 1SS8 heptamer and BIOMT-related tetradecamer assembly is provided in Supplementary Figure S1.

The resulting density grid had 1.0 A spacing and contained 188 by 186 by 120 voxels. Its integrated density was consistent with the expected electron count from the atom-derived model, supporting its use as a practical protein-scale density representation. Element counts, density settings, grid memory, construction time, and electron-count checks are given in Supplementary Table S1.

5.6. GroEL isosurface meshes, assembly, and decimation

Five isosurface levels were extracted from the GroEL density field. These surfaces defined two model families: Model A, a C7 heptamer, and Model B, a D7 tetradecamer assembled by appending the BIOMT-related copy using the transform (x, -y, -z). This reused mesh components rather than reconstructing density from atoms.

The 50% threshold tetradecamer mesh was used as the representative protein-scale mesh. After quadric decimation to approximately 20% of the original mesh, component count was preserved and the maximum absolute relative volume error across the decimation summary was 1.57 x 10^-3. Projection-level comparison against the reference density projection remained highly correlated before and after decimation. Detailed point counts, cell counts, volumes, and projection metrics are given in Supplementary Table S1.

These results show that the protein-density-derived mesh representation preserves the low-q projected-density quantities used by the framework after substantial decimation, although not necessarily all internal protein-density detail.

5.7. GroEL template-library demonstration and radial-control check

The GroEL template library used the D7 tetradecamer model and two coarse polyprism variants representing peripheral density changes. Symmetry-aware D7 sampling reduced 201 candidate rotations to 143 representative rotations; with three variants, the final library contained 429 templates. Representative model-variant projections and preview diffraction patterns are shown in Supplementary Figure S3.

The public experimental comparison used 76 manually curated GroEL shots. The protein-derived library was slightly and consistently better than the radial-profile-preserving control, but the separation was small. This result should therefore be interpreted as a limitation-aware modeling demonstration rather than strong GroEL orientation-retrieval validation. The detailed score distribution and paired comparison are shown in Supplementary Figure S4 and summarized in Supplementary Table S1.

5.8. Public-data application summary

The ID57 and GroEL cases play different roles. ID57 provides the stronger retrieval-oriented public-data validation: a 240-orientation symmetry-aware core-shell nanoparticle library recovered all noisy synthetic queries exactly and outperformed a radial-profile-preserving randomized control in all 209 public experimental paired comparisons. GroEL provides a protein-density modeling and scalability demonstration: a public PDB structure was converted into a smooth electron-density grid, assembled into heptamer and tetradecamer meshes, decimated with stable projection-level behavior, and used to generate a D7 symmetry-aware template library.

Together, these studies show that the validated kernel is usable beyond analytical test objects. The method supports reproducible nanoparticle retrieval tests and can be extended to protein-density-derived models, while the control comparisons define the limits of what can be claimed from low-q single-shot data alone.
