6. Discussion

This work presents a projected-density forward-simulation framework for low-q single-shot diffraction patterns from mesh-defined particle models. The method represents particles as closed, oriented surface meshes, computes projected density by signed surface-depth rasterization, and samples the detector-plane q-space region using a chirp z-transform. It is not a full source-to-detector simulator; it is a sample-level scattering kernel for rapid generation of ideal low-q patterns from candidate morphologies and orientations.

The results support three conclusions. First, the numerical kernel is accurate for the tested analytical and synthetic cases. Second, the projected-density representation is computationally efficient when the desired output is a selected detector-plane low-q region rather than a full three-dimensional reciprocal-space volume. Third, the same workflow can be used in reproducible public-data applications, with ID57 providing the stronger retrieval-oriented validation and GroEL demonstrating extension to protein-density-derived meshes.

6.1. Role of the projected-density approximation

The projected-density approximation is useful when the scientific question concerns coarse morphology, projected shape, size, anisotropy, or approximate orientation. In this regime, detector-plane scattering is strongly influenced by electron-density contrast integrated along the beam direction. Computing that projection directly avoids point-scatterer filling or dense three-dimensional voxel allocation when only a two-dimensional low-q detector region is needed.

This scope is also the main limitation. The method is not designed to model high-q structural detail, finite Ewald-sphere curvature, multiple scattering, pulse propagation, radiation damage, detector response, photon-counting statistics, or experiment-specific background. It should therefore be viewed as a compact particle-scattering component that can be embedded in larger workflows, not as a replacement for complete experimental simulation packages.

6.2. Advantages of the oriented-mesh representation

The oriented surface-mesh representation gives the framework a broad geometry domain. Analytical reference shapes, polyhedra, composite particles, scalar-field isosurfaces, and protein-density-derived meshes can all be handled through the same projection interface, without deriving a new analytical form factor for each object class.

The signed rasterization step is the key numerical mechanism. With closed, consistently oriented meshes, front-facing and back-facing surface contributions reconstruct the projected path length through the enclosed volume. The validation results show that this mechanism conserves projected mass across orientations and reproduces low-q scattering references with small errors. For smooth shapes, remaining disagreement with ideal analytical volumes reflects finite mesh approximation as well as rasterization error.

The same representation supports piecewise-uniform density models. Different mesh components can carry different density contrasts, allowing core-shell particles, inclusions, multiple particles, or density-subtraction models to be simulated by linear combination. This capability was used in the ID57 model and provides a route for more complex candidate libraries.

6.3. Computational implications

The performance benchmarks show that the method is practical for repeated ideal low-q pattern generation in the tested GPU environment. Runtime increased with detector image size and q-grid size, and the CZT transform became a major cost component at larger output grids. Mesh face count alone was not a sufficient predictor of runtime; projected pixel coverage, rasterized fragments, image size, and q-grid size were more informative.

The strongest structural advantage is memory scaling. Dense voxel approaches allocate a three-dimensional grid even when the output of interest is a two-dimensional detector-plane region. The projected-density workflow instead uses a two-dimensional projection image, a two-dimensional q-grid, and mesh arrays, avoiding unused reciprocal-space volume and reducing memory pressure.

End-to-end orientation-library throughput was limited more by orchestration than by the numerical kernel alone. Batching, reusable GPU buffers, reduced synchronization, and compact result handling are therefore the most direct performance-improvement targets.

6.4. Interpretation of ID57 retrieval

The ID57 application is the strongest public-data validation in this study. Synthetic self-retrieval confirmed that the template library, masking, scoring, and symmetry bookkeeping were internally consistent. Experimental retrieval then showed that the structured core-shell library outperformed a radial-profile-preserving randomized control for the public paired comparisons.

This supports the claim that the projected-density model captures model-specific two-dimensional low-q features in the ID57 images, not merely an average radial intensity envelope. The result should still be interpreted as candidate-model retrieval rather than proof of ground-truth orientation recovery for each shot, because the public frames do not provide true orientations and may include detector artifacts, background, finite sampling, and model mismatch.

6.5. Interpretation of the GroEL extension

The GroEL analysis addresses a different question from ID57. It tests whether the mesh-based workflow extends to protein-scale density models from public structural data. Density construction, isosurface extraction, C7 and D7 mesh assembly, decimation, projection validation, and template generation show that this extension is feasible.

The retrieval comparison for curated GroEL shots should be framed cautiously. The protein-derived templates were slightly and consistently better than the radial-profile-preserving control, but the separation was small. The value of the GroEL case is therefore methodological: it demonstrates that public PDB-derived density can be converted into a mesh-based projected-density model and propagated through symmetry-aware template generation, while also showing why control comparisons are needed to prevent overinterpretation.

6.6. Reproducibility and public-data scope

A recurring goal of this study is to make the validation independent of private experimental data. The manuscript therefore uses analytical references, synthetic public-safe morphologies, performance benchmarks, CXIDB public nanoparticle data, and public protein structural data. Earlier private droplet or deformation examples are not used as evidence for the main claims, making the scope narrower but more reproducible.

The public-data strategy clarifies what each validation layer contributes. Analytical references establish numerical correctness. Synthetic self-retrieval checks implementation consistency. Performance benchmarks establish cost and memory behavior. Public-data retrieval and control comparisons test whether the workflow provides useful candidate-model information in realistic data. Reduced output packages, CSV summaries, JSON metadata, and visual comparisons let readers inspect the evidence without rerunning every large intermediate calculation.

6.7. Limitations

Several limitations remain. The forward model assumes that the projected-density approximation is appropriate for the q-range and morphology question. High-q reconstruction, detailed molecular scattering, Ewald-sphere effects, detector-count modeling, fluence variation, and background modeling require additional physics. The method also assumes valid mesh geometry; open surfaces, inconsistent normals, self-intersections, or poorly chosen isosurface thresholds can produce incorrect projected densities.

The scoring and retrieval pipeline is also limited. Low-q single-shot retrieval is ambiguous, and many candidate models can produce similar detector-plane patterns. Log-correlation, annular ROIs, scale/background fitting, and radial-profile controls make the comparisons reproducible, but different ROIs, masks, q-ranges, background models, or scoring functions could change rankings.

The current implementation has performance limitations at the library-orchestration level. Single-pattern kernel timing is faster than end-to-end orientation-library wall time, showing significant Python-loop and synchronization overhead. The GPU backend also depends on CUDA through CuPy. Systems without NVIDIA CUDA support can use CPU paths, but should not expect the same acceleration without a backend redesign.

The protein-density extension has its own approximations. The GroEL density model uses smoothed atom-derived Gaussian density and isosurface layers, not a full experimental electron-density reconstruction. The polyprism variants are coarse model perturbations rather than refined structural models. The GroEL comparison therefore demonstrates pipeline feasibility and limitations, not high-confidence molecular orientation recovery.

6.8. Future extensions

Several extensions follow naturally from this work. Numerically, the projection kernel could be tested against additional analytical shapes, non-convex objects, multi-component density models, and higher-accuracy quadrature or rasterization references. CZT sampling could also be adapted to nonuniform detector q sampling or experimentally defined ROIs.

Performance improvements should focus on batched projection, batched CZT evaluation, reduced host-device synchronization, reusable GPU buffers, and compact result storage. Modeling extensions could add detector response, photon statistics, fluence variation, background models, and beamline-specific calibration layers around the sample-level kernel.

Additional public datasets would strengthen validation. The most useful tests would pair structured template libraries with well-defined controls and, where possible, independent orientation or morphology information. ID57 shows the value of radial controls for nanoparticle retrieval, while GroEL shows how controls prevent overstatement when the signal is dominated by radial-envelope information.

Overall, the projected-density framework is most useful as a fast, geometry-general, reproducible forward-modeling layer for low-q single-shot diffraction. Its main strength is not that it solves every part of experimental diffraction analysis, but that it provides a compact and validated kernel for generating candidate detector-plane patterns across mesh-defined morphologies.
