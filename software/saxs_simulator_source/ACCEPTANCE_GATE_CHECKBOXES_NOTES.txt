Acceptance threshold checkboxes
================================

This version adds an independent Use checkbox for each hard acceptance gate in
Auto Screen. Only checked gates are used to decide accepted=True/False.

Notes:
- Score-term checkboxes and weights remain separate. They control the total score.
- Acceptance threshold checkboxes control hard pass/fail gates.
- The former n_bins threshold control is removed from the UI. Feature extraction
  uses a fixed n_bins = 500 in the current workflow.
- A2-A6 phase gate still uses harmonic_phase_error_weighted_A2_A6_deg.
