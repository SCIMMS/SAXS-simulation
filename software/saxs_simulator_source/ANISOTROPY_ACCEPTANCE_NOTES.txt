Auto Screen 2D anisotropy acceptance update
===========================================

This build clarifies and fixes how A2-A6 harmonic anisotropy is used in Auto Screen acceptance.

Previous behavior:
- harmonic corr >= threshold used the mean profile correlation over the selected harmonic orders.
- However, the phase-error threshold still used only A2_phase_error_deg.
- Therefore A3-A6 phase mismatch could affect total_score through the A2-A6 phase score term, but not the hard accepted/rejected gate.

Updated behavior:
- harmonic corr >= threshold uses harmonics_mean_corr_A2_A6.
- phase err <= deg now uses harmonic_phase_error_weighted_A2_A6_deg.
- A2_phase_threshold_pass is retained in the CSV for backward compatibility.
- harmonic_phase_threshold_pass and harmonic_phase_threshold_max_deg were added to the CSV.

Interpretation:
- harmonic corr: similarity of A2, A3, A4, A5, A6 anisotropy amplitude profiles vs q.
- A2-A6 phase err: weighted mean orientation/phase mismatch across A2-A6; lower is better.
- angular corr: zero-shift phi-profile correlation in the selected harmonic q range.
