# GitHub Upload Checklist

Use this checklist before uploading the package to a private GitHub repository.

## Repository Visibility

- Start as a private repository.
- Add the professor as a collaborator after the first upload.
- Do not make the repository public until the manuscript status and data policy
  are confirmed.

## Files Included

- Manuscript text drafts and current Word draft.
- Main figure/table assets and source data.
- Supplementary figure/table assets and source data.
- Curated validation package.
- SAXS simulator source files.

## Files Excluded

- Raw CXIDB downloads.
- Packaged executables and PyInstaller build folders.
- Python virtual environments and cache files.
- Copyrighted article PDFs.
- Temporary Word lock files.

## Before Public Release

- Confirm final author list and affiliations.
- Confirm end matter: acknowledgements, funding, conflicts of interest, and data
  availability.
- Confirm whether any AI-tool disclosure is required.
- Replace internal notes with final public wording.
- Create a tagged release for the submitted or accepted version.
