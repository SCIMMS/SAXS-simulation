# IUCr Format Notes For Professor Review

These notes summarize manuscript-format items that are easy to miss when
preparing a Journal of Synchrotron Radiation submission.

## Manuscript Components

- Separate synopsis is required.
- Abstract should be concise and should not rely on direct figure/table/equation
  references.
- Keywords should include at least five terms or phrases.
- End matter needs professor confirmation: acknowledgements, funding, conflicts
  of interest, and data availability.

## Figures And Tables

- Figures should be placed near first mention and numbered in one continuous
  sequence.
- Multi-panel figures should use clear panel labels such as `(a)`, `(b)`, and
  `(c)`.
- In-image titles should be avoided when the caption can carry the explanation.
- Tables should be editable Word tables where possible, with concise headings
  and footnotes only when needed.

## Equations And References

- Word equation objects or MathML-pasted equations are preferred over image
  equations.
- References should follow the journal author-year style in the final document.
- The current numbered reference map is only an internal planning aid.
